# التحقق من v1.4 SIMPLE

نجحت **24 مجموعة تحقق**: صياغة ملفات Lua الثمانية بمفسر Lua 5.4؛ 9 مجموعات لإدارة جلسات السيرفر؛ فحص غياب دالة قراءة موديل الكيان وفحوص التصادم والبحث القديمة من العميل؛ و13 حالة محاكاة كاملة للعميل. اجتاز JavaScript أيضًا `node --check`.

فحوص السيرفر تغطي الصلاحيات، العزل، البدء المكرر، الإكمال المزور، استعادة bucket، التوقف، قيود حالة اللاعب، السعة، heartbeat والمهلة، وإزالة جلسة المنقطع.

| حالة محاكاة العميل | النتيجة |
|---|---|
| تشغيل كامل | 6 مراحل، 10 لقطات، 4 أوامر موسيقى، وتنظيف كامل |
| أرض أعلى بـ0.5 متر | أخذ القياس الاختياري وإكمال العرض |
| ESC | إيقاف العرض واستعادة اللاعب وحذف الكيانات |
| موديل غير موجود | خطأ واضح وتنظيف وإعادة اللاعب |
| مقاعد غير كافية | رفض قبل العرض وتنظيف الجلسة |
| فشل إنشاء مركبة | تنظيف جميع الكيانات المنشأة قبل الفشل |
| تعذر وضع المركبة على الأرض بالدالة | استمرار العرض اعتمادًا على موضع الأرض المعروف |
| عدم جاهزية NUI | إنهاء آمن بدل بقاء اللاعب عالقًا |
| تعطل navmesh | إكمال العرض؛ النسخة تستخدم المشي المباشر |
| تعطل جميع مهام المشي | إكمال العرض دون رفض علامة البوت |
| تعطل القيادة | نزول الفرقة من موضعها الحالي واستمرار الفيلم |
| تعطل الخروج المعتاد | استخدام مهمة الخروج الفوري وإكمال الفيلم |
| استثناء دالة قياس الأرض | استخدام ارتفاع الأرض المرجعي وإكمال العرض |

في المحاكاة، دالة `GetEntityModel` ترمي استثناء دائمًا إن استدعيت؛ نجحت الحالات لأن النسخة لا تستدعيها. هذه حالة اختبار لغياب مسار الخطأ، وليست محاكاة لمحرك streaming الحقيقي.

في التشغيل الكامل: مدة محاكاة 119 ثانية تقريبًا؛ 17 بوتًا، 5 مركبات، 3 أغراض. حذفت الكيانات الـ25، وتوقفت الموسيقى والكاميرا، واستعيد موضع اللاعب واتجاهه وحالته. أول إطلاق نار بعد 53 ثانية تقريبًا، بعد الوصول والإنذار.

## حدود النتيجة

هذه اختبارات السكربت عبر بيئة Lua وسيرفر وواجهات natives محاكاة. **لم يتوفر GTA V أو عميل FiveM لتشغيل المشهد فعليًا.** لا تقيس النتائج تصادم خريطة GTA أو حركة المركبات والمروحية أو دقة الرماية أو الإضاءة أو مظهر اللقطات داخل اللعبة.

اختير مركز ثابت في ساحة المطار أمام نقطة سبون الطائرات الأصلية في إعدادات QBCore. المرجع: [qb-garages/config.lua](https://github.com/qbcore-framework/qb-garages/blob/main/config.lua)، منطقة `intairport`. المرجع يثبت نقطة السبون وارتفاعها؛ موضع الساحة أمامها وحركة AI يحتاجان مشاهدة داخل اللعبة.

بعد التركيب يفترض ظهور `v1.4 SIMPLE scene ready` في F8. ظهور `v1.3` أو أخطاء بحث الساحة القديمة يدل على تشغيل الملفات السابقة.

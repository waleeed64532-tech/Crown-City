# FBI Cinematic — QBCore 1.3.0

[تحميل الإصدار 1.3 مباشرة من GitHub](https://github.com/waleeed64532-tech/Crown-City/raw/refs/heads/fbi-cinematic-download/fbi-cinematic/FBI-Raid-QBCore-v1.3.zip)

إصلاح قراءة الأرض `8.09 / 5.90`: معايرة ارتفاع الرصيف من التصادم، فصل الأرض عن أسطح الأجسام، تعديل مواقع الحراس حول عوائق صغيرة، وفحص كل زوايا الكاميرا قبل العرض. فحص مبكر للموديلات والمقاعد، واستعادة مشي AI عند تعطل navmesh بعد فحص الطريق.

1. فك الضغط وأوقف الريسورس القديم.
2. استبدل مجلد `qb-fbi-cinematic` كاملًا في `resources/[local]/`؛ لا تدمج ملفات أو إعدادات إصدار قديم.
3. من كونسول السيرفر نفذ `restart qb-fbi-cinematic`.
4. داخل اللعبة اكتب `/fbiraid` في الشات وأنت حي وعلى قدميك خارج المباني.

بعد نجاح الفحص تظهر في F8 رسالة `v1.3 Preflight passed`. الكاميرات والموسيقى والبوتات تعمل تلقائيًا، وESC يعيدك إلى مكانك.
